# Curso de Hacking Ético: Do Desenvolvedor ao Pentester (OWASP Top 10)

Bem-vindo ao curso prático de Hacking Ético desenhado especificamente para programadores Python e MySQL. Este curso utiliza a estrutura do **OWASP Top 10** como guia para explorar vulnerabilidades, entender a mente de um atacante e, o mais importante, aprender a mitigar esses riscos no código.

## 🚀 Objetivo do Curso
Transformar a sua perspetiva de desenvolvimento "fazer funcionar" para uma perspetiva de segurança "como isto pode ser quebrado". Ao longo deste curso, você irá:
- Compreender os fundamentos de cada vulnerabilidade do OWASP Top 10.
- Desenvolver scripts em **Python** para automatizar testes de segurança.
- Explorar e proteger bases de dados **MySQL**.
- Praticar com laboratórios e exercícios progressivos.

## 📂 Estrutura do Repositório
O curso está dividido em módulos, cada um focado em uma categoria do OWASP Top 10:

1. **[Introdução ao Hacking Ético](./00_intro/README.md)** - Mentalidade de Pentester e Setup.
2. **[A01: Broken Access Control](./01_broken_access_control/README.md)** - Falhas de autorização.
3. **[A02: Cryptographic Failures](./02_cryptographic_failures/README.md)** - Proteção de dados sensíveis.
4. **[A03: Injection](./03_injection/README.md)** - SQLi, Command Injection e mais.
5. **[A04: Insecure Design](./04_insecure_design/README.md)** - Falhas na arquitetura.
6. **[A05: Security Misconfiguration](./05_security_misconfiguration/README.md)** - Erros de setup.
7. **[A06: Vulnerable and Outdated Components](./06_vulnerable_components/README.md)** - Gestão de dependências.
8. **[A07: Identification and Authentication Failures](./07_authentication_failures/README.md)** - Quebra de login.
9. **[A08: Software and Data Integrity Failures](./08_integrity_failures/README.md)** - CI/CD e integridade.
10. **[A09: Security Logging and Monitoring Failures](./09_logging_failures/README.md)** - Visibilidade de ataques.
11. **[A10: Server-Side Request Forgery (SSRF)](./10_ssrf/README.md)** - Requisições maliciosas.

## 🛠️ Ferramentas Utilizadas
- **Python 3.x**: Para automação e scripts de exploração.
- **MySQL**: Para prática de injeção e proteção de dados.
- **Requests / BeautifulSoup**: Para interação web.
- **Scapy**: Para análise de rede básica (opcional).

## 🛡️ Aviso Legal
Este conteúdo é estritamente para fins educacionais e de segurança defensiva. O uso destas técnicas em sistemas sem autorização explícita é ilegal e antiético. O objetivo é tornar-se um melhor desenvolvedor através da compreensão da segurança.
